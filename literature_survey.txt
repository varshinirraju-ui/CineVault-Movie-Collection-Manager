RESEARCH GAP
------------
Existing movie-management systems emphasise online databases, APIs, cloud
services, user accounts and social features. CineVault meets a different
academic need: showing how a practical movie-management application can be
built with C, a singly linked list, dynamic memory allocation and persistent
file storage, while still offering a usable web interface.

Gap statement: there is a gap in simple academic movie-management systems that
demonstrate a practical web application built with C and a singly linked list
with persistent file storage. CineVault fills it with a working prototype.
